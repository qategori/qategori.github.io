Cara mengatur gambar ikon Speed Dial pada aplikasi browser

30 Jun 2020 Tips Blogger








Bagi Anda yang memiliki sebuah situs web maupun blog pribadi mungkin pernah menambahkan alamat situs Anda di speed dial atau panggilan cepat pada aplikasi browser favorit Anda. Ya memang, speed dial sudah menjadi fitur penting pada aplikasi browser dimana fitur ini memudahkan penggunanya untuk mengakses situs favoritnya tanpa perlu membuka bookmark atau bahkan menuliskan alamat situsnya.

Tutorial juga tersedia di YouTube:


Pada artikel ini saya akan berbagi tips untuk mengatur gambar ikon pada speed dial di aplikasi browser favorit Anda seperti: Chrome, Opera, Microsoft Edge, Safari Browser, serta ikon pada menu iPhone dan Android, hal yang tidak kalah penting juga yaitu ikon Favicon situs Anda. Silahkan ikuti langkah-langkah berikut: 

  • Xtgem
  • ZArchiver
  • Logopit plus
  • Realfavicongenerator


Siapkan akun Xtgem 


Xtgem berguna untuk menyimpan gambar ikon dan file tambahan lainnya (penyimpanan cloud). Silahkan daftar akun pada Xtgem dan buat situs domain untuk penyimpanan file nantinya. contoh: qategori.xtgem.com 


Buat gambar logo 


Saya sarankan gunakan aplikasi Logopit plus dan pilih kanvas logo (720x720) pixel dan simpan dengan format PNG.

Unggah file ke Realfavicongenerator 


Masuk ke Realfavicongenerator dan klik "Select your image". Tunggu proses converter kemudian sesuaikan gambar ikon menurut selera Anda. 


Sesuaikan gambar ikon satu persatu:

  • Ikon Favicon
  • Ikon menu pada iPhone
  • Ikon menu pada Android
  • Ikon menu pada Microsoft, dll.




Pada pengaturan icon Android diatas, klik Assets >> beri tanda centang pada "Declare the icon in HTML code". Jika sudah selesai mengatur gambar ikon, atur alamat penyimpanan file-file ikon yang nanti akan digunakan sebagai file hosting. Karena saya menyarankan file hosting yang gratis seperti Xtgem, maka tulis alamat situs domain yang sudah anda buat pada langkah pertama.


Tambahkan alamat folder yang akan digunakan untuk menyimpan file-file ikon Anda, contoh: 

http://qategori.xtgem.com/logo/

Kemudian klik "Generator Favicon kode HTML", tunggu sampai proses converter selesai, 


Unduh file Zipnya (Favicon package) dan salin kode html yang akan ditempelkan pada situs Anda. 

Extract file Zip dengan ZArchiver


Buka ZArchiver, cari file zip yang sudah didownload tadi kemudian extract pada folder baru agar mudah ditemukan. 

Unggah file ikon ke Xtgem 


Masuk Xtgem dan klik tombol "edit" pada domain situs Anda >> klik "File Browser" >> klik "Buat folder", buat folder dengan nama "logo" >> klik  "Unggah file", unggah semua file yang sudah diextract tadi sampai selesai.

Memasang kode HTML
