Mengganti icon sistem di Windows 10 Mobile

13 Feb 2017 Windows MobileTips Windows Mobile


Pada kesempatan ini kami akan share cara mengganti icon system di Windows 10 Mobile dengan menggunakan Interop Tools agar tampilan smartphone menjadi lebih unik dan terkesan lebih keren 😎.

Disarankan:
  • OS sudah Windows 10 Mobile
  • Perangkat sudah diunlock/hack [Baca: Cara unlock Windows 10 Mobile mengunakan Interop Tools ]

Unduh file icon di 👇:
  1. Icon_TTT
  2. Segmdl24
  3. Segmdl27
  4. Segmdl2a
  5. Segmdl311


"Saran: Silahkan buat folder dengan nama Fonts di folder Documents di Memori Internal untuk menyimpan file icon yang akan dipakai, jangan di Memori External."



Langkah-langkah:
  1. Buka aplikasi Interop Tools

    Interop Tools


  2. Klik This Device

    This Device



  3. Klik Registry Browser

    Registry Browser



  4. Klik HKEY_LOCAL_MACHINE (HKLM)

    HKLM



  5. Klik Software

    🐇oftware



  6. Klik Microsoft

    Microsoft



  7. Klik Windows NT

    WindowsNT



  8. Klik CurrentVersion

    CurrentVersion



  9. Klik Fonts

    Fonts



  10. Klik Segoe MDL2 Assets (TrueType)

    Segoe MDL2 Assets (TrueType)


  11. Ubah alamat Registry value data sesuai alamat icon yang akan dipakai 👇

    Silahkan salin alamat ini 👇

    Ubah nama_icon.ttf sesuai nama icon yang akan dipakai. Contoh 👇 C:\Data\Users\Public\Documents\Fonts\segdml311.ttf
  12. Jika sudah selesai klik Tanda Centang dan keluar dari aplikasi, kemudian Restart smartphone.

Oke 👌 cukup sekian, Terimakasih sudah menyempatkan waktunya untuk datang kesini ☺ .
