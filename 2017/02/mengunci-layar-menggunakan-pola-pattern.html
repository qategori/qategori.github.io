Mengunci layar menggunakan pola / pattern di Windows 10 Mobile

13 Feb 2017 Windows MobileTips Windows Mobile


Pada kesempatan ini saya akan berbagi trik mengunci layar smartphone Windows 10 Mobile menggunakan pasword pattern atau pola, mungkin agan2 bosen dengan fitur defaultnya atau mungkin mau iseng mempraktekan trik ini 🤔 itu kalo agan2 mau 😂 hehe, karena sampai saat ini Microsoft hanya menyediakan pasword mengunakan PIN. Jika ingin mempraktekan ikuti langkah-langkah di bawah ini 👇



Disarankan:
  • OS sudah Windows 10 Mobile
  • Perangkat sudah diunlock/hack [Baca: Cara unlock Windows 10 Mobile mengunakan Interop Tools ]

Alat dan Bahan:
  • 8 Zip [ Unduh ]
  • Lollipop Locksreen [ Unduh ]


"Sebelum melakukan trik ini nonaktifkan dulu pasword PINnya. 👉 Buka Settings > Account > Sing-in option > Require Sign-in [never / tidak pernah]"

Langkah selanjutnya:

A. Instal kedua aplikasi:
  1. Unduh dan Instal 8 ZIP lite
  2. Unduh file Lollipop Lockscreen dan extract lewat 8 ZIP lite. 🙋

    "Saran: Jika ingin selalu menggunakan fitur ini. Buatlah folder Apps di folder Documents memori internal, dan extract file Lollipop di folder Apps tersebut. Ini untuk menghindari resiko semisal memori external sewaktu-waktu dilepas"

  3. Setelah diextract selanjutnya instal Lollipop lewat Interop Tools. Jika belum tau silahkan ke sini [ Contoh instal aplikasi lewat Interop Tools ].


B. Atur Lollipop Lockscreen:
  1. Setelah terinstal, buka Lollipop Lockscreen > klik Change Photo > pilih background yang akan di gunakan 👇
  2. Geser kebawah dan klik Advance Setting kemudian geser ke kiri dua kali
  3. Pada jendela pattern lock > klik set pattern, atur pattern agan di sini 👇

  4. Tutup aplikasi tersebut dan restart HP agan


C. Aktifkan pengaturan:
  1. Buka Pengaturan/Setting > Personalisasi > Layar kunci/Lockscreen
  2. Pilih Lollipop Lockscreen sebagai background, kemudian klik Buka aplikasi / Open app 👇
  3. Pada jendela Lollipop klik Use this application as live lock screen > klik yes 👌
  4. Klik tombol kembali di navbar, tutup semua aplikasi
  5. Pada jendela home, klik tombol power untuk mengunci layar tunggu 5 detik sambil berdoa kemudian klik tombol power / buka layar.


"Note: Jika tiba-tiba aplikasi ngga work, cukup lakukan langkah C1 sampai C3"

Semoga berhasil 👌, sebelumnya saya mohon maaf atas semua kekurangannya 😊.


Wassalamualaikum Wr. Wb.
