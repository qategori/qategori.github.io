Cara Unlock Windows 10 Mobile dengan Interop Tools

31 Jan 2017 Windows MobileTips Windows Mobile




Untuk melakukan unlock menggunakan Interop Tool OS harus sudah menggunakan Windows 10 Mobile.

Alat dan bahan:
  • 8 ZIP lite [ Unduh ]
  • File Interop Tools [ Unduh ]


Langkah-langkah:


A. Instal Interop Toll

  • Instal 8 ZIP lite dan unduh file Interop Tools
  • Buka Pengaturan (Setting) > Pembaruan & keamanan (Update & security) > Untuk pengembang (For Developer), lakukan seperti ini 👇

  • Extract file Interop Toll lewat 8 ZIP lite
  • Instal terlebih dahulu 5 file yang ada di Depencies ARM, kemudian instal InteropToolsApp_1.9.370.0_arm
  • Tunggu 10 detik, kemudian buka Interop Toll di daftar aplikasi



B. Unlock Telpon

  • Buka Interop Tool > Interop Unlock, lakukan seperti ini 👇
  • Restart telepon
  • Buka kembali Interop Tool
  • Jika berhasil tampilan Interop Toll seperti ini 👇



Oke 👌, Selamat mencoba
