Cara Menggunakan SHAREit di Windows 10 Mobile

19 Jan 2017 Windows MobileAplikasiTips Windows Mobile





SHAREit adalah aplikasi untuk mentransfer file dengan mengunakan jaringan wifi, yang saat ini mulai populer di perangkat Windows 10 Mobile, Android, iOS, dan OS lainnya. Dengan mengunakan sambungan wifi tentu pengiriman akan lebih cepat dibandingkan dengan teknologi bluetooh saat ini.

Oke gan, kita kembali ke topik 'Cara mentransfer file lewat SHAREit di Windows 10 Mobile dengan Android'. Disini saya mengunakan Windows 10 Mobile build.576 dengan Samsung Android dan 100% berhasil, jika cara ini tidak berjalan mulus di perangkat lain saya mohon maaf 😅hehe 😁jangan kecewa gan. Sebelum mencoba pastikan mengunakan SHAREit versi terbaru di kedua OS, lihat tangal berapa artikel ini terbit barangkali bulan depan SHAREit update versi lagi, jadi beda kasus lagi gan. Oke ☺

Cara Mengirim file lewat SHAREit di Windows 10 Mobile ke Android

  1. Buka SHAREit di Windows 10 Mobile > klik Send/Kirim
  2. Pilih file yang akan dikirim > klik OK
  3. Pada jendela pencarian, klik No WIFI dibagian kiri bawah warna merah
  4. Di jendela initial, tunggu hingga muncul nama dan pasword wifi
  5. Buka SHAREit di Android > buka opsi di pojok kiri atas > klik pengaturan
  6. Hidupkan lebih suka wifi yang sama dan Matikan enkripsi wifi
  7. Kembali ke halaman awal SHAREit > klik Terima/Receive.
  8. Buka pengaturan wifi di Android > sambungan dengan wifi dari Windows 10 Mobile, lihat nama dan paswordnya di jendela SHAREit Windows 10 Mobile. Jika berhasil jendela SHAREit Android seperti ini
  9. Pada jendela SHAREit Windows 10 Mobile, klik start
  10. Tunggu hingga proses transfer selesai ☺



Cara mengirim file lewat SHAREit dari Android ke Windows 10 Mobile / Cara menerima file lewat SHAREit di Windows 10 Mobile
  1. Buka SHAREit Android > buka opsi > klik webshare
  2. Pilih file yang akan di bagi > klik krim
  3. Tetap di jendela ini, diamkan saja dan Mobile hotspot Android akan otomatis aktif. Jika tidak aktifkan secara manual
  4. Buka pengaturan wifi Windows 10 Mobile > sambungkan dengan Mobile hotspot Android
  5. Buka Microsoft Edge > masukan alamat yang ada di jendela SHAREit Android > Enter
  6. Klik tombol Download di kanan file > klik Save
  7. Tunggu hingga proses Download selesai
Saat menerima file, pada Windows 10 Mobile tidak perlu mengunakan SHAREit. Cukup dengan Microsoft Edge 😎 Selamat mencoba semoga berhasil
