Cara download "Pembaruan telepon" dan "Peta Offline" lewat Data seluler di Windows Mobile

4 Apr 2017 Windows MobileTips Windows Mobile




Mungkin banyak Winuser yang tidak menggunakan fitur Data Usage di Windows Mobile yang memiliki banyak fungsi yang tidak kalah penting dari aplikasi lainnya. Seperti topik pada artikel ini, bahwa Anda bisa mengunakan fitur ini untuk mengunduh Pembaruan telepon dan Data Peta offline mengunakan sambungan internet lewat Data seluler.

"Fitur ini selain untuk meninjau pengunaan data internet, Anda juga bisa menggunakannya untuk membatasi pengunaan internet Anda. Misalnya Anda ingin mengatur berapa Mb yang akan digunakan dalam minggu ini untuk mengakses internet."

 Terkait : Kasus "Resuming" Windows 10 Mobile telah teratasi di Build 15063.2
Untuk mengunduh pembaruan telepon lewat jaringan Data seluler cukup atur Data usage dengan data Tanpa batas. Lebih jelasnya seperti ini:

1. Masuk Pengaturan 
2. Klik System, kemudian Data Usage 
3. Atur pengunaan secara Unlimited (Tanpa batas)
