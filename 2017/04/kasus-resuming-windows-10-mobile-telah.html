Kasus "Resuming" Windows 10 Mobile telah teratasi di Build 15063.2

4 Apr 2017 Windows Mobile




Microsoft sampai saat ini masih selalu memberikan pembaruan pada sistem operasi untuk perangkat mobilenya (Windows 10 Mobile), hal ini memang harus dilakukan Microsoft untuk mengejar ketertinggalan dari para pesaingnya dan bukan tidak mungkin bila Microsoft akan memberikan inovasi yang lebih baru seperti fitur iris scanner, misalnya.

Terkait: Cara downlod "Pembaruan telepon" dan "Peta Offline" lewat Data seluler di Windows Mobile

Hal yang tidak asing bagi Winuser adalah kasus "Resuming", hal ini sering dijumpai di perangkat Windows Mobile saat mereka beralih/switch dari aplikasi ke aplikasi lain ketika perangkat menjalankan aplikasi secara bersamaan di latar belakang (multitasking). Hal yang sangat mengecewakan lagi adalah apabila perangkat tidak mampu melanjutkan aplikasinya (force close).

Pada Build 15063.2 sebagai persiapan update selanjutnya, hampir tidak ditemukan jendela "Resuming" pada layar muka Windows 10 Mobile ketika melakukan switch dari applikasi ke aplikasi lain, walaupun terkadang menjumpai jendela layar hitam yang hanya kurang dari satu detik.


Ketika perangkat menjalankan empat aplikasi secara bersamaan, diantaranya adalah Instagram, Messenger, WhatsApp, dan BBM kasus "Resuming" tidak dijumpai ketika beralih ke aplikasi lain, khusunya WhatsApp dan BBM yang terkenal dengan kasus "Resuming"-nya saat berada di Windows Phone 8.1 maupun Windows 10 Mobile pada build sebelumya.

Saat perangkat dicoba untuk menjalankan beberapa aplikasi, perangkat membatasi dengan tujuh aplikasi yang dapat dijalankan dilatar belakang secara bersamaan.
