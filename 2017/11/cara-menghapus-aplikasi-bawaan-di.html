Cara menghapus aplikasi bawaan di Windows 10 Mobile

12 Nov 2017 Tips Windows Mobile





Ada beberapa aplikasi bawaan pada smartphone yang mungkin tidak terlalu penting dan jarang sekali digunakan, sehingga hanya mempersempit ruang penyimpanan smartphone Anda. Namun ada beberapa aplikasi bawaan yang tidak dapat dihapus lewat pengaturan default seperti View 3D, Xbox, dll. Bagi Anda yang ingin menghapus aplikasi bawaan pada Windows Mobile silahkan ikuti langkah-langkah berikut:


Disarankan:
  • OS sudah Windows 10 Mobile
  • Perangkat sudah diunlock/hack [Baca: Cara unlock Windows 10 Mobile mengunakan Interop Tools ]



Langkah-langkah:

  • Buka aplikasi Interop Tolls
  • Klik This Device




  • Klik Applications







  • Geser ke kanan untuk membuka Package List, tunggu sampai proses memuat daftar aplikasi selesai.

  • Klik "All types" dan pilih "Main"




  • Cari applikasi yang akan dihapus, kemudian klik dan tahan. Silahkan klik "Uninstall"
